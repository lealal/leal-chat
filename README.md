# Personal Chat Project

This project is a FastAPI backend + Vite/React frontend AI chat application deployed on Azure. The backend interacts with an Azure AI Project, and the frontend consumes the backend API.

The goal was to create a simple agent that would respond questions about my experience. The webapp can be accessed from my site: https://lealal.github.io/

The agent uses some knowledge sources to provide responses and a simple gpt-mini model. The responses might vary in quality due to the limitation of the model for RAG
